# DARK.exe starter

Стартовый каркас: Telegram Mini App, FastAPI, aiogram, PostgreSQL и Docker Compose.

## Перед запуском
1. Нужен VPS с Docker Compose и доменом, настроенным на VPS.
2. Нужен HTTPS-сертификат; Telegram Mini App должен открываться по HTTPS.
3. Скопируйте `.env.example` в `.env`, укажите токен бота, HTTPS URL и сильный пароль базы.
4. Запустите `docker compose up -d --build`.
5. Настройте Caddy/Nginx для HTTPS и проксирования на `127.0.0.1:8000`.

Проверка API: `/api/health`.

Важно: это стартовая версия, а не завершённый публичный продукт. Перед функциями, зависящими от личности пользователя, нужно добавить серверную проверку подписи Telegram `initData`, защиту от злоупотреблений и резервные копии. Не публикуйте `.env` и не отправляйте токен бота в чат.
