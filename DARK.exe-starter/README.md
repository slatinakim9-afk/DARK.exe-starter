# DARK.exe

Чёрно-красная панель управления в стиле секретной системы.

## Возможности

- Анимированный интерфейс.
- Статус системы и модулей.
- Лента событий.
- Переключатели GHOST MODE и AUTO REPLY в демонстрационном режиме.
- Поддержка Telegram Web App.
- API на FastAPI.

## Запуск локально

Установи зависимости:

```bash
pip install -r requirements.txt
```

Запусти API:

```bash
uvicorn app.api.index:app --host 127.0.0.1 --port 8000
```

Открой в браузере:

http://127.0.0.1:8000

## Настройка

Скопируй `.env.example` в `.env` и заполни нужные переменные окружения.

Не публикуй токены и пароли в GitHub.

## Деплой

Для Vercel укажи папку `DARK.exe-starter` как Root Directory, если репозиторий содержит проект во вложенной папке.

Проверь настройки проекта и логи деплоя после публикации.

## Важно

Переключатели панели демонстрационные. Они не включают реальную скрытность или автоматические ответы во внешних сервисах.
